# **Judul Tugas:** Pengembangan Aplikasi Keamanan Informasi Berbasis Kriptografi (KriptoApp)

## Tugas Akhir Mata Kuliah Kriptografi

KriptoApp adalah aplikasi keamanan informasi yang mengintegrasikan kriptografi, autentikasi pengguna, enkripsi pesan dan file, steganografi, serta teknologi blockchain untuk menjaga keamanan dan integritas data.
